Exported Diagram Catalog
========================

This page renders the SVG artifacts exported from draw.io sources.  The
corresponding ``.drawio`` files are stored next to the SVG exports in this
repository and can be opened with diagrams.net/draw.io.  Change the source
first, export its SVG again, and commit both files in the same Merge Request.
The exported SVGs retain an embedded copy of their draw.io model and must not
be edited as standalone XML.

This catalog is an artifact index and preview page.  The system behaviour,
interface contracts and configuration represented by the diagrams are defined
in :doc:`adaptive_traffic_light_system_design`; they are not duplicated here.
